## Measurement status

There are **no new measured LCP, INP, CLS, bundle-size, TTFB or production-performance results** from this audit. HTML/SSR correctness, source inspection and a successful build do not establish Core Web Vitals.

Historical evidence only: `output/seo/home-mobile-lighthouse.json` is a **10 October 2026** localhost Home lab run using Lighthouse 13.5.0. It reported performance 77, LCP about 5.95s, CLS 0 and total blocking time 119.5ms. It predates later inventory/content/consent changes and must not be presented as the current result. TBT is not INP, and a single local lab run is not field CWV.

The next owner-authorized performance pass should use representative mobile devices/connections and real interactions on Home, Buy, Rent, Services, Contact and an authorized listing; compare consent states; inspect long tasks, image choices, maps and backend timings. Use Search Console/CrUX field data where available against the brief's targets: LCP ≤2.5s, INP ≤200ms and CLS ≤0.1. No current pass/fail claim is justified without those results.
